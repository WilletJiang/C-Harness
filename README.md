C Harness is a small C17 library and CLI for durable agents: streaming model calls, local tools, fresh-context subagents, resumable sessions, and optional skills, MCP servers and plugins. It uses libcurl, SQLite, pthreads, yyjson and tomlc17. Skills, MCP and plugins are disabled by default; when enabled, it reads existing Codex resources on demand and keeps loaded context bounded.

Build with `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, then `cmake --build build --parallel`; run `ctest --test-dir build --output-on-failure` and try `./build/ah_embed`. Use `./build/ah --help` for the CLI, or link `ah::ah` from CMake. See [usage](docs/usage.md), [extensions](docs/extensions.md) and [subagents](docs/subagents.md) for configuration and examples.
