C Harness is a small C17 library and CLI for durable agents: asynchronous tools, fresh-context subagents, automatic context checkpoints, and text, image and file inputs. It uses libcurl, SQLite, pthreads, yyjson and tomlc17. Skills, MCP servers and plugins are disabled by default and can read existing Codex resources on demand.

Build with `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, then `cmake --build build --parallel`; run `ctest --test-dir build --output-on-failure` and try `./build/ah_embed`. Use `./build/ah --help` for the CLI, or link `ah::ah` from CMake. See [usage](docs/usage.md), [context](docs/context.md), [extensions](docs/extensions.md), [subagents](docs/subagents.md) and [content](docs/content.md) for configuration and examples.
