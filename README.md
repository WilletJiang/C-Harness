C Harness is a small C17 SDK and headless CLI for agents: JavaScript tool orchestration with [flow](docs/flow.md), resumable tools, durable signals and waits, keyed child calls, fresh-context subagents, context checkpoints, and native text, image and file inputs and tool results. It uses libcurl, SQLite, pthreads, yyjson and tomlc17. Skills, MCP servers and plugins are disabled by default and can read existing Codex resources on demand.

Run `./test` to configure, build and test the project, then try `./build/ah_embed` or `./build/ah_durable`. Use `./build/ah --help` for the CLI, or include `ah/sdk.h` and link `ah::ah` from CMake. Swift hosts can import the `CHarness` package. See [SDK integration](docs/sdk.md), [batch web search](docs/web-run.md), [durable work](docs/durable.md), [usage](docs/usage.md), [context](docs/context.md), [extensions](docs/extensions.md), [subagents](docs/subagents.md) and [content](docs/content.md).
