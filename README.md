C Harness is a small C17 SDK and headless CLI for durable agents: asynchronous tools, fresh-context subagents, automatic context checkpoints, and native text, image and file inputs and tool results. It uses libcurl, SQLite, pthreads, yyjson and tomlc17. Skills, MCP servers and plugins are disabled by default and can read existing Codex resources on demand.

Build with `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, then `cmake --build build --parallel`; run `ctest --test-dir build --output-on-failure` and try `./build/ah_embed`. Use `./build/ah --help` for the CLI, or include `ah/sdk.h` and link `ah::ah` from CMake. Swift hosts can import the `CHarness` package. See [SDK integration](docs/sdk.md), [usage](docs/usage.md), [context](docs/context.md), [extensions](docs/extensions.md), [subagents](docs/subagents.md) and [content](docs/content.md) for configuration and examples.
